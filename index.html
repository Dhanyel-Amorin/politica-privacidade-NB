Política de Privacidade

Esta Política de Privacidade se aplica ao aplicativo Nutri Basic, desenvolvido por DA Software.

Última atualização: 28 de abril de 2026.

1. Coleta de dados

O aplicativo Nutri Basic não coleta, armazena, compartilha ou transmite dados pessoais dos usuários.

As informações inseridas no aplicativo, como dados usados para cálculos nutricionais ou de IMC, são processadas localmente no próprio dispositivo e não são enviadas para servidores externos.

2. Permissões do dispositivo

O aplicativo não solicita permissões sensíveis do dispositivo, como câmera, microfone, localização, contatos, arquivos, telefone, SMS ou notificações.

3. Compartilhamento de dados

Como o aplicativo não coleta dados pessoais, nenhuma informação é vendida, compartilhada ou transferida para terceiros.

4. Serviços de terceiros

O aplicativo não utiliza serviços de terceiros para análise, publicidade, rastreamento ou coleta de dados.

5. Segurança

O Nutri Basic foi desenvolvido para funcionar de forma local no dispositivo do usuário. Ainda assim, recomendamos que o usuário mantenha seu dispositivo atualizado e protegido.

6. Crianças

O aplicativo não coleta intencionalmente dados de crianças ou adolescentes. Como nenhum dado pessoal é coletado, não há armazenamento ou compartilhamento de informações de menores de idade.

7. Alterações nesta política

Esta Política de Privacidade poderá ser atualizada futuramente para refletir melhorias no aplicativo ou mudanças legais. A versão atualizada será disponibilizada nesta página.
